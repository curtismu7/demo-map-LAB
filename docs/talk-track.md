# Talk track

Two minutes, Mock mode (the made-up sample). Say first: "this is a sample; none of these apps is real".

1. **The idea.** "One page that answers: where do I start for this story? Each row is a story or a Ping product. Under it are the standalone apps that belong there, then the AI-DEMO2 pages for the same story."
2. **The rows.** "Personal Agent, Digital Worker, then PingOne, PingFederate, PingGateway, PingOne Privilege, PingOne Authorize and PingOne Protect. The number next to a title is how many apps are in it."
3. **A card.** "Name, a kind chip (Demo tells a story, Tester probes something, Tool is infrastructure), what it does, and Open. The status chip says Running, Not running or Needs setup, in words, from the shelf's own check."
4. **One app, two rows.** "The claims gateway sits under PingGateway and PingOne Authorize: it uses both, so it shows in both."
5. **More apps.** "Anything that matches no row lands at the bottom, so nothing on the shelf is hidden."
6. **Filter and collapse.** "Type part of a name or a description. Collapse a row you are not presenting; the count stays."
7. **Real, if you own it.** "Real reads your own local demo shelf, read-only, and builds the page links on your AI-DEMO2 address. It names your real apps, so do not share that screen."

If asked "who decides what goes in a row?" - `data/rows.json`: ids, tags and Ping products per row. Edit it and reload.
