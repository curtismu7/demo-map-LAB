# demo-map-lab

Tool-tier standalone app (port 7808): "Demo Map", a one-page map of the demo family. One row per story or product (Personal Agent demo, Digital Worker agent, PingOne, PingFederate, PingGateway, PingOne Privilege, PingOne Authorize, PingOne Protect, then "More apps"), each with the standalone apps that belong in it (cards) and the AI-DEMO2 pages for it (links). Scaffolded from env-map-LAB. Mock = the made-up `data/sample-shelf.json`; Real = the local demo shelf (`GET <SHELF_URL>/api/shelf`, loopback only, read-only) plus `AI_DEMO2_URL` for the page links.

- Run: `./scripts/run.sh` (http://127.0.0.1:7808/) or `HOST_PORT=7808 docker compose up --build -d` (OrbStack, Mock only). Test: `npm test` (server = `node --test test/*.test.js`, a glob; web = vitest against the real server in a child process; repo scans = `node --test scripts/*.test.mjs`). Preflight: `npm run doctor`. Reset: `npm run reset`. UI standard: `bash scripts/check-ui-standard.sh` (vendored `web/src/standalone-ui.css` must equal the canonical copy on GitHub origin/main of AI-DEMO-Standalone; re-vendor from origin, then `--pin`).
- Rows are data: `data/rows.json` (schema `demo-map-rows/1`: id, title, summary, `match` {ids, tags, pingProducts}, pages [{label, path}]). An app is in a row when its id equals or contains a `match.ids` entry, or a tag is in `match.tags`, or a Ping product is in `match.pingProducts` (all case-insensitive); it can be in several rows; unmatched apps go to "More apps". Edit the file and reload; no rebuild.
- Server: `boundedJson.js` (size cap + iterative depth check), `rows.js` (rows parser: caps, no echo), `match.js` (the rule), `view.js` (rows + counts + page hrefs), `shelf.js` (shelf validator + the one loopback fetch), `baseUrl.js` (origin validation), `config.js` (`AI_DEMO2_URL`, `SHELF_URL` from env or this app's own `.env`; Real refused off a loopback bind), `source.js`, `app.js` (info, mode, reset, map), `safety.js`, `netguard.js`, `doctor.js`, `health.js` (`demo-health/1`).
- Web: `components/Row.jsx` (collapsible row), `AppCard.jsx` (card; Open only for a plain http(s) URL, `rel="noopener noreferrer"`), `lib/filter.js`. React is bundled by Vite: no CDN, no web font. Never use `innerHTML` or `dangerouslySetInnerHTML`; a repo test fails on it.
- Rules that bite: one port, 7808, `127.0.0.1:` only (a test pins it); `POST /api/mode` is exactly `{ source }` (409 when Real is not configured); compose has `restart: unless-stopped` (rule 21); Real never follows a redirect and never contacts a non-loopback origin; nothing fetched is echoed in an error or a log; the sample carries only `.example` hosts, no UUIDs, no e-mail, no @mentions; settings only from this app's own `.env` (never `~/Documents`); the Docker image has no volumes and no Real settings.
- Theme tokens only (no colour literals in `app.css`), no purple, both themes, 375px; every control has a visible border (dark control contrast rule); status chips always carry a word.
- `docs/shelf-entry.json` has no `catalogId` on purpose. It is NOT registered in demo-shelf-LAB `data/demos.json` yet; that needs the owner's go-ahead together with the repo.
- No AI attribution anywhere (owner rule 2026-11-07).
